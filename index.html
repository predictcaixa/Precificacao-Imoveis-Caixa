Documentação da API

Como integrar o ImóvelML à sua aplicação

Base URL
http://localhost:8000

Acesse http://localhost:8000/docs para o Swagger UI interativo gerado automaticamente pelo FastAPI.

Endpoints disponíveis
MétodoRotaDescrição
GET/Health check
POST/predictPredição de um imóvel
POST/predict/batchPredição em lote (até 100)
GET/regioes/statsEstatísticas por região
GET/modelo/infoMétricas e metadados do modelo
POST/relatorioGerar relatório por região
Exemplo — POST /predict
curl -X POST http://localhost:8000/predict \
  -H "Content-Type: application/json" \
  -d '{
    "regiao":    "centro",
    "area":      90,
    "quartos":   3,
    "banheiros": 2,
    "vagas":     1,
    "idade":     5,
    "suite":     1,
    "sacada":    1,
    "piscina":   0
  }'
