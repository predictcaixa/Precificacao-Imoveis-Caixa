# Precificação de Imóveis - Caixa

Este repositório reúne todos os experimentos, estudos e implementações relacionados ao desenvolvimento do **Site de Precificação de Imóveis da Caixa**.

O objetivo é centralizar o desenvolvimento da aplicação, permitindo a validação de ideias, testes de funcionalidades e evolução contínua do projeto.

##  Objetivos

- Desenvolver uma plataforma para precificação de imóveis.
- Realizar experimentos e provas de conceito (PoCs).
- Validar algoritmos e regras de negócio.
- Centralizar o código-fonte e a documentação do projeto.

## 📂 Estrutura do Projeto

```text
.
├── docs/             # Documentação
├── src/              # Código-fonte da aplicação
├── tests/            # Testes automatizados
├── experiments/      # Experimentos e protótipos
└── README.md
```
